# I-class 강의자료 자동 분류 (비공식)

인하대 I-class에서 받은 강의자료를 과목별 폴더에 자동으로 저장하는 크롬 확장 프로그램입니다.
인하대학교의 공식 프로그램이 아닙니다.

## 설치와 사용

1. [크롬 웹 스토어](https://chromewebstore.google.com/detail/cnejcckajdimidcejalbmoleeciahlmc)에서 "Chrome에 추가"를 누르세요. 업데이트는 크롬이 자동으로 해요.
2. I-class에서 수강 중인 과목 페이지에 한 번씩 들어가세요. 한 번 들어간 과목부터 인식돼요.
3. 평소처럼 강의자료를 받으면 `다운로드\I-class\<과목명>`에 저장돼요.

인식 전에 받은 파일이나 과목 밖(메인 화면, 전체 공지 등)에서 받은 파일은 `I-class\미분류`로 가요.

## 저장 위치

크롬 확장은 다운로드 폴더 안에만 저장할 수 있어서, 저장 위치는 `다운로드\I-class`로 정해져 있어요.
바탕화면 등 다른 폴더에서 바로 열고 싶다면, 파일을 하나 받은 뒤 그 폴더에 `I-class` 폴더의 바로가기를 만들어 두세요.

- Windows: 다운로드 폴더의 `I-class`를 오른쪽 클릭 → (Windows 11은 "더 많은 옵션 표시") → 보내기 → 바탕 화면(바로 가기 만들기). 다른 폴더에 두려면 생긴 바로가기를 그 폴더로 옮기세요.
- Mac: Finder에서 Option+Command를 누른 채 `I-class` 폴더를 원하는 폴더로 끌어다 놓으세요. 가상본(바로가기)이 생겨요.

## 설정

주소창 오른쪽 퍼즐 아이콘 → "I-class 강의자료 자동 분류"를 누르면 설정 페이지가 열려요.

- **학기별 폴더로 나누기**: 켜면 `I-class\2026년 2학기\<과목명>`처럼 학기 폴더 아래에 저장해요. 계절학기는 `2026년 여름학기`, `2025년 겨울학기` 폴더가 되고, 비교과는 학기를 알 수 없어서 `I-class\비교과\<강좌명>`에 모아요.
- **인식된 과목**: 지금까지 인식된 과목 목록이에요. 과목별 "삭제", 학기별 "목록 지우기"로 뺄 수 있어요.
- **폴더 이름**: 과목 목록의 "폴더 이름" 칸에 적은 이름으로 저장해요. 비워 두면 과목명을 쓰고, 폴더 이름에 못 쓰는 문자(`\/:*?"<>|`)는 띄어쓰기로 바꿔요. 이미 받은 파일은 옮겨지지 않으니 기존 폴더 이름도 직접 바꿔 주세요.

## 문제 해결

- **파일이 "미분류"로 가요** → 그 과목 페이지에 한 번 들어간 뒤 다시 받아 보세요.
- **파일을 받을 때마다 저장 위치를 물어봐요** → 크롬 설정 → 다운로드에서 "다운로드 전에 각 파일의 저장 위치 확인"을 끄세요. `다운로드\I-class`를 링크(정션·심볼릭 링크)로 다른 폴더에 연결해 두었다면 그 연결을 지우세요. 크롬은 다운로드 폴더 밖으로 이어지는 링크를 막아요.
- 그 밖의 문제나 제안: [GitHub Issues](https://github.com/sjh030728/iclass-sorter/issues)
