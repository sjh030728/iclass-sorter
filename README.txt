I-class 강의자료 자동 분류 (비공식)
=====================================

인하대 I-class에서 받은 강의자료를 과목별 폴더에 자동으로 저장하는 크롬 확장 프로그램입니다.

[설치]
1. 크롬 웹 스토어에서 설치: https://chromewebstore.google.com/detail/cnejcckajdimidcejalbmoleeciahlmc
   링크를 열고 "Chrome에 추가"를 누르세요. 업데이트는 크롬이 자동으로 해요.
2. I-class에서 수강 중인 과목 페이지에 한 번씩 들어가기
   (한 번 들어간 과목부터 인식돼요. 인식 전에 받은 파일은 "미분류" 폴더로 가요.)

[저장 위치]
- 기본: 다운로드\I-class\<과목명>
- 다른 폴더에 저장하려면 (선택 사항):
  1) 바탕화면 연결 도구 받기:
     https://github.com/sjh030728/iclass-sorter/releases/latest/download/desktop-link.zip
  2) 압축을 풀고 실행
     Windows: desktop-link.bat 실행
       "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누르세요.
     Mac: desktop-link.command 더블클릭
       열 수 없다는 창이 뜨면 "완료"를 누르고 시스템 설정 → 개인정보 보호 및 보안 →
       아래쪽 "그래도 열기"를 누르세요. (예전 macOS는 Control-클릭 → "열기")
       그래도 안 되면 터미널을 열고 "bash "(뒤에 띄어쓰기)를 입력한 뒤
       desktop-link.command 파일을 터미널 창에 끌어다 놓고 Return을 누르세요.
  3) 폴더 선택 창이 뜨면 원하는 폴더를 고르세요.
     Windows: 파일을 저장할 폴더예요. 기본은 바탕화면\인하대학교 예요.
       다시 실행하면 다른 폴더로 바꿀 수 있어요. (이미 받은 파일은 원래 폴더에 남아요.)
     Mac: 파일은 그대로 다운로드/I-class 에 저장되고, 고른 폴더에 그 폴더로 가는
       "인하대학교" 바로가기가 생겨요. 기본은 바탕화면이에요.
       (Mac 크롬은 다운로드 폴더 밖에 저장하게 하면 매번 저장 위치를 물어봐서 이렇게 해요.)
  연결이 끝나면 압축을 푼 파일은 지워도 돼요.

[설정]
주소창 오른쪽 퍼즐 아이콘 → "I-class 강의자료 자동 분류"를 누르면 설정 페이지가 열려요.
(퍼즐 메뉴에서 핀을 눌러 두면 툴바에 항상 보여요.)
- 학기별 폴더로 나누기: 켜면 I-class\2026년 2학기\<과목명> 처럼 학기 폴더 아래에 저장해요.
  계절학기는 2026년 여름학기, 2025년 겨울학기 폴더가 돼요.
  비교과는 학기를 알 수 없어서 I-class\비교과\<강좌명> 에 모아요.
- 인식된 과목: 지금까지 인식된 과목 목록이에요.
- 폴더 이름 바꾸기: 과목 목록의 "폴더 이름" 칸에 원하는 이름을 적으면 그 이름으로 저장해요.
  비워 두면 과목명을 그대로 써요.
  ※ 이미 받은 파일은 옮겨지지 않아요. 기존 폴더도 탐색기에서 같은 이름으로 바꿔 주세요.
     (파일을 받기 전에 이름을 정해 두면 이 작업이 필요 없어요.)

[문제 해결]
- (Mac) 파일을 받을 때마다 저장 위치를 물어봐요 → 예전 연결 도구를 쓴 경우예요.
  새 연결 도구를 받아 다시 실행하세요. 바탕화면/인하대학교 폴더는 다운로드/I-class 로 옮겨지고
  같은 자리에 바로가기가 생겨요.
- 파일이 "미분류"로 가요 → 그 과목 페이지에 한 번 들어간 뒤 다시 받아 보세요.
- 예전에 압축 파일로 설치했어요 → chrome://extensions 에서 예전 확장을 삭제하세요.
  둘 다 켜져 있으면 저장 위치가 엉킬 수 있어요. 과목 목록과 폴더 이름은 새로 설정해야 해요.
